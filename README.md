# World Explorer - React Application


## Overview
Country Explorer is a React-based frontend application that consumes data from the REST Countries API to display information about countries worldwide. The application allows users to search, filter, and view detailed information about different countries.

## Live Demo
[View the live application on Netlify](https://cute-bublanina-dd47f9.netlify.app/)


## Technologies Used
- **Frontend**: React 
- **CSS Framework**: Tailwind CSS
- **API**: REST Countries API
- **Build Tool**: Vite
- **Deployment**: Netlify

## API Endpoints Used
1. `GET /all` - Fetch all countries
2. `GET /name/{name}` - Search countries by name
3. `GET /region/{region}` - Filter countries by region
4. `GET /alpha/{code}` - Get detailed information about a specific country

## Installation
To run this project locally, follow these steps:

1. Clone the repository:
```bash
git clone 
cd country-explorer
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```
